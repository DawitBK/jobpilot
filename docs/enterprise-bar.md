# Enterprise bar: JobPilot scorecard

**DONE** means there is code and a test (the evidence column says where), **PARTIAL** means part
of it exists, **TODO** means it does not exist yet. The status is deliberately honest.

Status as of 2026-10-29. Added since 2026-10-17: outbox dispatcher and notifications, plans and quotas, two-step
sign-in, encrypted secrets, AI drafting with evidence checks, review policy, employer emails, demo seed, browser tests.
